# Bootstrap card

Requirements: POSIX host + C11 compiler. No installed NanoC, packages or downloads.

```sh
cc -std=c11 -O2 build.c -o builder
./builder bootstrap
./build/nanoc --version
./builder test
CC=clang ./builder test --sanitize
```

| Stage | Built from | Emits |
|---|---|---|
| `build/stage0` | Frozen `bootstrap/src` C + `bootstrap/include` | `build/stage1/src` C |
| `build/stage1-nanoc` | Stage 1 C, generated from `src` NanoC | `build/stage2/src` C |
| `build/nanoc` | Stage 2 C, generated by self-hosted NanoC | `build/stage3/src` C |

Every module's stage 1, 2 and 3 emitted C must match byte for byte. Any translation,
compile or comparison failure stops the build. Tests link stage 2 compiler modules.
`build` caches verified builds by source/header/seed/driver contents, compiler and
sanitizer mode. `bootstrap` forces the complete chain. `clean` removes all stages.

Edit `src/**/*.nc`; indented NanoC functions implement the entire compiler,
including lexer, expansion, layout, macros, CT/BT, assembly and CLI `main`.
Shared C headers declare libc-facing types/contracts. The C builder/tests remain C.

```sh
./builder snapshot    # verify, then regenerate the committed C seed + frozen headers
./builder bootstrap  # prove the regenerated seed builds the same compiler
```

Seed C is generated, compacted and frozen; do not maintain a second implementation.
Snapshot C retains `main` and compiles using only C11/libc/POSIX. Every committed
source, including seed files, remains at most 100 physical lines.
